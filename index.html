📦 Getting an AI Model File

Think of whirl-llm as the engine and the model file as the brain. The application needs one model file to work. Model files use the GGUF format, which is a widely used and openly documented way of packaging AI models into a single file you can copy and move around like any other document.

Model files are downloaded from public model libraries. Look for a file whose name ends in .gguf. Sizes range from a few gigabytes for small fast models up to tens of gigabytes for large detailed ones. On a machine with 32 GB of memory, a model between 4 GB and 12 GB is a comfortable starting point that loads quickly and responds fast.

Place the downloaded model file in the same folder as the whirl-llm application. Keeping everything together in one folder makes the next steps simple and lets you move the whole setup later by dragging a single folder.

🧠 What whirl-llm Does for You

  • Runs large language models locally on your own AMD Radeon graphics card.
  • Works entirely offline once your model file is in place, so nothing you type leaves your computer.
  • Uses the AMD HIP interface to talk directly to your graphics card on Windows.
  • Supports MXFP4 model formats for efficient memory use on modern AMD hardware.
  • Includes speculative decoding, a technique that speeds up text generation so answers appear sooner.
  • Reads standard GGUF model files, so you are not locked into a single model provider.
  • Ships as a self-contained folder with no installer, no background services and no account sign-up.
  • Targets RDNA 3.5 and RDNA 4 graphics, including Strix Halo class systems.

🖥️ Your First Conversation

Once the dark window is open and waiting, using the application is as simple as typing. Here is what to expect on your first run.

  1. Point it at your model file. When the application asks for a model, type the name of the .gguf file you placed in the folder, or drag the file into the window if dragging is supported.
  2. Let it load. You will see progress messages while the model is read from disk and copied into memory. A larger file takes longer the first time. Do not close the window while this happens.
  3. Type a message and press Enter. The text you write appears as your question, and the answer prints below it, word by word, as it is generated.
  4. Continue the conversation. Keep typing follow-up questions. The application remembers the earlier part of the conversation so answers stay on topic.
  5. Close the window when you are finished. There is nothing to save manually and nothing left running in the background.

🛠️ Troubleshooting Common Problems

The window opens and closes immediately

This usually means the model file could not be found or the graphics driver needs updating. Make sure the .gguf file sits in the same folder as the application, then open the AMD Radeon software and check that your driver is current. Restart your PC and try again.

Windows blocks the download or will not run the file

Open File Explorer, right-click the downloaded file and choose "Properties". Near the bottom of the General tab, tick the box labeled "Unblock", then click "Apply". If the blue protection box appeared during launch, click "More info" and then "Run anyway".

Loading takes a very long time

Model files are big, and reading them from a slow drive takes patience. Move the model file to your fastest internal drive, close other memory-hungry programs, and give it a few minutes on the very first load. Later launches are usually faster because Windows keeps recently used files in memory.

The output looks scrambled or the application reports a graphics error

Update the AMD Radeon driver from the official AMD website, then fully restart the computer so the new driver loads. Avoid running the application while a game or video editor is using your graphics card at the same time.

I want a different style of answer

Try a different model file. Answer style comes from the model itself, not from whirl-llm, so switching to another .gguf file changes how detailed, formal or creative the replies are.

💡 Tips for Best Performance

  • Keep the application folder and your model file on the same fast drive.
  • Plug in the power adapter on a laptop. Battery mode often limits graphics performance.
  • Close browser tabs, games and video editors while a model loads.
  • Start with a smaller model and move up in size once you know everything works.
  • Set your Windows power mode to Best Performance for longer sessions.
  • Keep at least a few gigabytes of free disk space so Windows can breathe.

🔄 Keeping Everything Up to Date

New releases of whirl-llm are published on the same download page. When a new version appears, download it, extract it into a fresh folder, and copy your .gguf model file across. There is no installer to remove and no registry entries to clean up, so updating simply means using the newer folder.

It is also worth checking your AMD graphics driver every few months. Driver updates regularly improve how quickly modern graphics hardware handles AI workloads, and whirl-llm benefits directly from those improvements.
